# O que este programa prova
1. *Validação Offline e Detecção de Fraude:* Prova que a catraca do ônibus valida o bilhete localmente usando hash segura (HMAC). Quando o ônibus descarrega os dados na nuvem, o sistema descobre se o mesmo bilhete foi usado duas vezes em ônibus diferentes.
2. *Isolamento entre Cidades (Envelope D):* Prova que o sistema de uma cidade (ex: Sumaré) pode sofrer uma sobrecarga sem afetar ou derrubar o sistema de outra cidade (ex: Campinas).
